Drop .ttf / .otf font files here to make edited PDF text match the original typeface.

When you edit a line, the editor needs the same font the PDF used. PDFs usually embed only the
letters they already show, so new characters need a real copy of the font. Name files like
Inter-Regular.ttf, Inter-Bold.ttf, Inter-Italic.ttf, Inter-BoldItalic.ttf (static files, not variable fonts).
Fonts installed in Windows are found automatically.
